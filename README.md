Simulador de ruleta en Java para jugar desde la consola.

## Cómo jugar

1. Ejecuta el programa
2. Elige una opción del menú:
   - 1 = Iniciar ronda
   - 2 = Ver estadísticas
   - 0 = Salir

## Tipos de apuesta

- R = Rojo
- N = Negro  
- P = Par
- I = Impar

## Requisitos

- Java JDK 22
